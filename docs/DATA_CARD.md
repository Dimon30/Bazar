# Данные Bazar

## Источник

Я использую [Amazon Shopping Queries Dataset (ESCI)](https://github.com/amazon-science/esci-data) с лицензией Apache 2.0. В наборе есть товары, поисковые запросы и оценки релевантности. Это не данные реальных пользователей Bazar.

## Какую часть данных я беру

Команда `ingest-esci` выбирает `small_version=1`, локаль `us` и первые `N` запросов после сортировки. По умолчанию `N=2000`. Такой выбор можно повторить на другом компьютере.

Исходное разделение на обучение и тест я не меняю. Для обучения использую только обучающую часть, а для расчёта метрик только тестовую.

## Метки

Я перевожу метки ESCI в числовые оценки:

- `E` - точное соответствие, оценка 3;
- `S` - замена, оценка 2;
- `C` - дополнение, оценка 1;
- `I` - нерелевантный товар, оценка 0.

## Ограничения

Эти данные подходят для проверки поиска, но не показывают реальные клики, покупки или выручку. События, которые записывает демонстрационный API, я помечаю как смоделированные и не использую для расчёта метрик ESCI.
